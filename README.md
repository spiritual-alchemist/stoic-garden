# The Stoic Garden

A garden that grows from **evidence, not effort**. It doesn't ask *did you do the reps* — Habitica already does that. It asks a question Habitica can't: *did the mindset actually show up, and what did it build.*

Four beds, already planted: the four cardinal virtues — **wisdom, justice, courage, temperance**. Once a day it asks *"where did today test you, and did you meet it?"* You tap the virtue that showed up, optionally jot one line. That tap is the only thing that makes a plant grow. Tap nothing and the bed stays bare — an honest garden has empty patches.

Over time two things make it a *mirror*, not a tracker:

- **The shape shows your asymmetry** — which virtues you're actually living versus the ones you keep meaning to.
- **Sprout → perennial** — a young plant wilts when neglected, but once a virtue has enough real evidence behind it, it *roots* into a tree that survives a missed day. That transition is the visible proof you built a trait, not a streak.

## Run it locally

No build step, no dependencies. Serve the folder over HTTP (a service worker needs http, not `file://`):

```bash
python3 -m http.server 4321
# open http://localhost:4321
```

## Put it on your phone

It's a PWA. Host the folder anywhere static over HTTPS (GitHub Pages is free) and, on the phone browser, use **Add to Home Screen**. It then opens fullscreen, works offline, and keeps your garden on the device.

## How it stores things

Everything lives in the browser's `localStorage` on the device — your lines never leave it. **Export** writes a JSON backup; **Import** merges a backup (additive by entry id, so you can carry the garden between phone and laptop). No account, no server.

## The growth model (all data-driven, in `js/data.js`)

- **Evidence** = number of *distinct days* a virtue was logged. Stage is read off the `STAGES` table (seed → sprout → young → flowering → rooted at 10 evidence days).
- **Health** = recency. A non-rooted plant wilts after `GRACE_DAYS` of neglect over a `WILT_WINDOW`. A rooted plant stays healthy regardless — a trait, not a streak.

## Layout

```
index.html            app shell
css/style.css         warm, calm, mobile-first; light + dark
js/data.js            virtues, growth rules, the mirror + echo (pure logic)
js/store.js           localStorage + JSON export/import
js/garden.js          the pixel-art engine (custom plants, wind, wilt, day/night)
js/app.js             UI wiring: daily composer, beds, mirror, echo
manifest.webmanifest  PWA manifest
sw.js                 offline shell cache
icons/                app icons (generated by tools/gen-icons.js)
tools/                icon generator + tests (test-logic.js, test-app.js)
```
